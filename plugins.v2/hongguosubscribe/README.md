# 红果短剧订阅（HongGuoSubscribe）

定时抓取红果短剧官网（https://hongguoduanju.com）的热播榜单，获取短剧标题、热度与评分，并按配置自动处理。

## 功能

- **数据源**：默认监控短剧热播榜，每次仅处理榜单前 10 条；可切换/追加真人剧、漫剧、AI剧热播榜及自定义榜单地址；
- **处理方式**：
  - 自动：先识别媒体信息添加订阅，识别失败时回退按标题搜索并下载；
  - 仅搜索下载：直接按短剧标题在 PT 站点搜索资源并下载（优先体积最大的资源）；
  - 仅订阅：只添加订阅，不下载。
- **过滤规则**：标题黑名单、最小热度（万）、最小评分；
- **去重**：按短剧 `series_id` 查重，已处理过的短剧不再重复处理。

## 配置说明

| 配置项 | 说明 |
| --- | --- |
| 启用 | 是否启用插件 |
| 代理 | 访问榜单网站及 PT 站点是否走代理 |
| 立即运行一次 | 开启后保存配置立即执行一次 |
| 执行周期 | cron 表达式，留空则每小时执行一次 |
| 处理方式 | auto / search / subscribe |
| 榜单 | 内置 hot-drama（短剧热播榜）、hot-real（真人剧热播榜）、hot-comic（漫剧热播榜）、hot-ai（AI剧热播榜），可多选 |
| 自定义榜单地址 | 追加自定义榜单页路径，多个用英文逗号分隔 |
| 最小热度 | 低于该热度（万）的短剧跳过，留空不限制 |
| 最小评分 | 低于该评分的短剧跳过，留空不限制 |
| 标题黑名单 | 命中即跳过，多个用英文逗号分隔 |

## 注意

- 短剧多为非标准媒体，TMDB 通常识别不到，默认走「按标题搜索下载」回退路径；
- 需要 MoviePilot 已配置可用的搜索/下载/订阅链路。
