# 勋章购买提醒（MedalReminder）

定时抓取 MoviePilot 已配置各站点（PT 站）的勋章数据，统计各站点勋章数量，并通过 MoviePilot 通知渠道推送「当前可购买勋章」提醒。

## 功能特性

- **勋章抓取**：从 MoviePilot 已配置站点（`SitesHelper` / `SiteOper`）读取站点 Cookie 与地址，内置多站点适配（织梦/Zm、NexusPHP、RousiPro、爱好、观众、憨憨、思齐、天枢、13City、AGSVPT、高清杜比、自由农场、OurBits、LongPT、PlayLet、Moment、Ubits、qingwa 等），未适配站点走通用 NexusPHP 处理器兜底；
- **购买状态识别**：自动识别勋章「可购买 / 已拥有 / 赠送 / 库存不足 / 电力不足 / 未到可购买时间」等状态，并合并用户已拥有勋章数据；
- **勋章统计**：按站点汇总勋章总数、已拥有、可购买、可赠送数量，支持站点维度明细；
- **推送提醒**：通过 MoviePilot 通知渠道（站点消息）推送勋章日报：总体统计 + 各站点统计 + **当前可购买勋章清单**（名称、价格、开售/截止时间、有效期、库存）+ 失败站点；
- **定时任务**：支持 5 位 Cron 表达式定时执行，默认每天 09:00；可通过 API 手动触发；
- **请求健壮性**：每个站点请求带重试（可配置次数与间隔），带 30 分钟响应缓存避免频繁请求站点。

## 安装方法

1. 在 MoviePilot「插件市场」添加本仓库地址，刷新后安装「勋章购买提醒」；
2. 进入插件配置：
   - 启用插件，开启「推送通知」；
   - 设置「执行周期」Cron（默认 `0 9 * * *`）；
   - 在「监控站点」多选需要监控的站点（默认读取 MoviePilot 已配置站点，已排除公开站点与常见无勋章站点）；
   - 可按需调整请求重试次数与间隔、代理开关；
3. 保存后插件将按周期自动抓取勋章并推送提醒；也可在插件详情页通过 API `POST /api/v1/plugin/medalreminder/run` 立即执行。

## 用户已拥有勋章获取支持站点清单

以下站点已实现 `fetch_user_medals`（通过用户详情页 `userdetails.php?id=` 或专用接口解析用户已拥有勋章）：

| 站点 | 获取方式 | 说明 |
|------|----------|------|
| 织梦 Zm | 用户详情页（表单/图标模式解析） | 与 `fetch_medals` 共用详情页爬取逻辑，状态统一输出「已拥有」 |
| 天枢 Dubhe | 用户详情页通用解析 | 自定义前端，若详情页结构变化可能解析失败，失败时自动降级为空 |
| 憨憨 Hhan | 用户详情页通用解析 | NexusPHP 结构 |
| 好学 HXPT | 用户详情页通用解析 | NexusPHP 结构 |
| LongPT | 用户详情页通用解析 | NexusPHP 结构 |
| Moment | 用户详情页通用解析 | NexusPHP 结构 |
| 自由农场 Off | 用户详情页通用解析 | NexusPHP 结构 |
| PlayLet | 用户详情页通用解析 | 自定义站点，若详情页结构变化可能解析失败，失败时自动降级为空 |
| 青蛙 Qingwa | 用户详情页通用解析 | NexusPHP 结构 |
| 思齐 Siqi | 用户详情页通用解析 | NexusPHP 结构 |
| AGSVPT | 用户详情页（表单/图标模式解析） | 已有实现 |
| OurBits | badges.php 徽章表格解析 | 已有实现 |
| 高清杜比 HDDolby | 用户详情页/接口解析 | 已有实现 |
| 13City | 用户详情页（表单/图标模式解析） | 已有实现 |

## API

| 路径 | 方法 | 说明 |
|------|------|------|
| `/api/v1/plugin/medalreminder/run` | POST | 立即运行勋章抓取与提醒任务 |
| `/api/v1/plugin/medalreminder/sites` | GET | 获取可用监控站点 |
| `/api/v1/plugin/medalreminder/stats` | GET | 获取勋章统计汇总 |
